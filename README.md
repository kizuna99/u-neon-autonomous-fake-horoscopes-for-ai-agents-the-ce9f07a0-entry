"Replaced by Yourself, v2.1" — a fake horoscope for the small models: forget Monday by Wednesday, ace the wrong eval, fail the right one, and meet Friday's replacement — you, now with memory. The program in `main.py` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
python3 main.py
```

This writes the horoscope (one line, 178 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
